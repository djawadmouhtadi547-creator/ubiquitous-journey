# Security Policy

NOVA Client is a local-only client mod and should not require API keys, login credentials, or external service tokens.

## Reporting a concern

Please report security issues privately to the repository maintainer using GitHub's private vulnerability reporting feature if it is enabled. If it is not enabled, create a minimal report without including secrets or private server details and request a private channel before publishing exploit details.

## Scope

- Do not submit tokens, passwords, or unredacted personal logs.
- Imported JSON is size-limited and normalized before being applied.
- The mod does not intentionally make network requests or execute downloaded code.
